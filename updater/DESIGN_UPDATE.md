# D&D v26 — Unified Design Update

This build combines the previous design-polish pass with the latest dashboard direction.

## Included
- Unified dark / purple visual language.
- More spacious dashboard hierarchy with KPI cards, goals, activity and analytics.
- Goals and revenue analytics remain below the primary workspace content.
- Cleaner Data & Safety action grid.
- Cleaner account/profile panel.
- Always-visible green balance beside the Producer role in the sidebar.
- The same green balance is shown when the account panel is opened.
- Bottom player remains fixed and visually separated from page content.
- Existing tested application logic is preserved; this update is focused on presentation and profile balance display.
