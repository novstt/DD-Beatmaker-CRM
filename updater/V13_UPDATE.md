# Beatmaker v13 — Design Update

This update is based on the working v12 desktop.

## Included
- New dark Beatmaker dashboard visual direction.
- Animated login/register authentication screen.
- Blurred application preview behind authentication.
- Smooth fade transitions when switching login/register.
- Working registration flow through `POST /api/auth/register`.
- Automatic login after successful registration.
- Existing Artists, Beats, Licenses, Stats, Notifications and Settings pages remain in the desktop build.
- Account controls remain available.

## Update
Replace the files from this ZIP in the corresponding project folders, then rebuild Docker and launch the desktop app.

Do not delete the PostgreSQL volume.
