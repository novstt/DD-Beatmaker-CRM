# D&D v26 — Phase 2A

Built from the verified Phase 1 FIX2 base.

## Added in Phase 2A
- Dashboard workspace panels for Follow-ups and Goals.
- Follow-up scheduling from Artist profile; double-click a due follow-up to mark complete.
- Goals with target/current/period and dashboard progress.
- Artist soft-delete into Trash + restore.
- Beat soft-delete into Trash + restore.
- Beat tags with quick tag action in Beat Library.
- Backup export to JSON from Settings.
- Keyboard shortcuts: Ctrl+K / Ctrl+F for global search.
- Stats now expose My Earnings, Other Producers' Beats and Messenger Earnings.
- Phase 2 earnings includes sales of the user's beats made by other messengers.
- API workspace endpoints for follow-ups, goals, favorites, tags, trash and backup.
- Existing Artist and Beat listings hide archived items.
- Re-adding an archived artist revives the user-artist link.

## Important
- Google Drive remains disabled in the business workflow.
- MP3 remains local-only in the desktop phase at this point.
- The verified Phase 1 license split rules remain unchanged.
- Docker runtime was not available in the build environment, so run the normal Windows Docker test on the project machine.
