# D&D v26 Phase 2G

## Goal engine
New goals always start at 0. Progress is calculated from the goal's creation timestamp, so historical revenue/sales do not fill a newly created goal. Completed goals remain visible.

## Analytics
Stats now expose conversion rate, buyers/contacted artists, revenue change vs the previous comparable period, and a top-artists revenue leaderboard.

## Audio safety
Local MP3 storage now checks for identical-file duplicates before adding a new beat.

## Email
Remembered email storage now uses a stable Windows APPDATA path plus QSettings fallback. Passwords are never stored.
