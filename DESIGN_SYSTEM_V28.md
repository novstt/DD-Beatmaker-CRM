# D&D v28 UI direction

- One 220px sidebar, one 64px top bar, one scrollable content canvas, one 56px player.
- Cards use a consistent 16–18px radius, 1px border, 16–20px internal spacing.
- Primary purple is reserved for actions/active navigation; green is financial positive/balance; amber is pending; red is destructive.
- Every page uses the same title/subtitle/header rhythm and avoids nested cards where a flat section is clearer.
- Tables/lists align numbers to the right and labels to the left.
- Empty states are compact and actionable.
