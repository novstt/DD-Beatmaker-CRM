# D&D v26 Phase 1

Built from the last working v24 base. Google Drive is removed from the active workflow.

Implemented in this phase:
- Artist -> Beat -> License workflow
- automatic producer/messenger split rules
- unlimited licenses per beat
- external or registered co-producers
- co-producer notifications
- MP3-only local drag/drop + playback
- richer artist list fields
- admin allow-list enforced by email
- Windows tray background mode
- PostgreSQL/Docker startup healthcheck

The remaining approved roadmap is intentionally staged after this core passes end-to-end testing.
